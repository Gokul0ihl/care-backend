What to build (in order)
  1. New table reception_emergencyregistration (one-to-one with emr_encounter): distinguishing marks, police station informed, triage level, medico-legal case number, accompanying person (title, first / middle / last name, country code, phone, relationship), same-as-WhatsApp flag.
  2. MLC number generator: MC-<year>-<sequence>, unique per facility, created on registration and copied to emr_encounter.external_identifier.
  3. UHID identifier config: one row in emr_patientidentifierconfig (display "UHID", unique) so patients can be searched by UHID.
  4. One "Register & Print" API: creates emr_patient + emr_encounter (encounter_class='emer') + the new row in a single transaction, filling CARE's required fields for unknown patients.
  5. Dashboard summary API: the four KPI numbers with the change versus last month.
  6. Waiting time: record when a token is called/served (not in emr_token today) so an average can be computed.
